# 日本著名演员（Japan）

日本影视产业孕育了众多享誉亚洲乃至世界的演员，从昭和时代的国民女星到平成、令和时代的当红偶像，他们在电影与日剧两大领域都留下了经典作品。以下 16 位演员兼顾经典与当红、男女均衡，均在中国观众中拥有较高知名度，是了解日本影视文化的入门之选。

---

## 1. 木村拓哉 (木村拓哉 / Kimura Takuya)

**全名**：木村拓哉 / Kimura Takuya

**中文常用称呼**：木村拓哉，粉丝常称"木村"、"拓哉"、"Kimutaku（キムタク）"

**代表作**：《华丽一族》華麗なる一族（2007，饰 万表铁平）、《律政英雄》HERO（2001，饰 久利生公平）、《恋爱世纪》ラブジェネレーション（1997，饰 片桐哲平）、《美丽人生》ビューティフルライフ（2000，饰 冲岛柊二）

**特点**：前 SMAP 成员，被誉为"日剧天王"，主演的日剧曾连续多年拿下收视冠军；广告代言之王，被视为平成时代最具影响力的男演员之一。辨识点是深邃眼神与标志性的爽朗笑容。

## 2. 新垣结衣 (新垣結衣 / Aragaki Yui)

**全名**：新垣結衣 / Aragaki Yui

**中文常用称呼**：新垣结衣，粉丝称"gakki（ガッキー）"，昵称"老婆"（中国网络流行梗）

**代表作**：《逃避虽可耻但有用》逃げるは恥だが役に立つ（2016，饰 森山实栗）、《恋空》恋空（2007，饰 田原美嘉）、《Legal High》リーガル・ハイ（2012，饰 黛真知子）、《紧急救命》コード・ブルー（2008，饰 白石惠）

**特点**：被誉为"国民老婆""治愈系女神"，笑容甜美亲切，是平面模特出身的代表性女演员；《逃避虽可耻但有用》中"恋舞"在中国网络爆红。辨识点是标志性的 Gakki 笑。

**照片**：<img src="images/jp_02_aragaki.jpg">

## 3. 堺雅人 (堺雅人 / Sakai Masato)

**全名**：堺雅人 / Sakai Masato

**中文常用称呼**：堺雅人，粉丝称"雅人叔"

**代表作**：《半泽直树》半沢直樹（2013，饰 半泽直树）、《Legal High》リーガル・ハイ（2012，饰 古美门研介）、《大奥～诞生》大奥〜誕生【有功・家光篇】〜（2012，饰 万里小路有功）、《盗钥匙的方法》鍵泥棒のメソッド（2012，饰 樱井武史）

**特点**：大器晚成的实力派，《半泽直树》"加倍奉还"创下平成日剧收视纪录；演技张力极强，既能演正剧又能驾驭夸张喜剧。辨识点是丰富的表情变化与富有磁性的台词功底。

**照片**：<img src="images/jp_03_sakai.jpg">

## 4. 石原里美 (石原さとみ / Ishihara Satomi)

**全名**：石原さとみ / Ishihara Satomi

**中文常用称呼**：石原里美，昵称"さとみ"、"十元"（中国粉丝爱称）

**代表作**：《非自然死亡》アンナチュラル（2018，饰 三澄美琴）、《失恋巧克力职人》失恋ショコラティエ（2014，饰 高桥纱绘子）、《朝5晚9》5じから9じまで（2015，饰 樱井润子）、《富贵男与贫穷女》リッチマン、プアウーマン（2012，饰 夏井真琴）

**特点**：中国知名度极高的"国民女神"之一，时尚带货能力极强，剧中穿搭常引发模仿热潮；《非自然死亡》中的法医形象深入人心。辨识点是甜美笑容与标志性的嘟嘴表情。

**照片**：<img src="images/jp_04_ishihara.jpg">

## 5. 菅田将晖 (菅田将暉 / Suda Masaki)

**全名**：菅田将暉 / Suda Masaki

**中文常用称呼**：菅田将晖，昵称"suda"、"苏打"（中国粉丝取的谐音爱称）

**代表作**：《3年A班：从现在起大家都是人质》3年A組-今から皆さんは、人質です-（2019，饰 柊一飒）、《民王》民王（2015，饰 武藤翔）、《啊，荒野》あゝ、荒野（2017，获日本电影学院奖最佳男主角）、《帝一之国》帝一の國（2017，饰 赤场帝一）

**特点**：当红实力派青年演员，戏路极广，从特摄剧出道到文艺片通吃，并凭借《啊，荒野》获日本电影学院奖最佳男主角；同时活跃于音乐领域。辨识点是清冷少年感与多变的银幕形象。

**照片**：<img src="images/jp_05_suda.jpg">

## 6. 广濑铃 (広瀬すず / Hirose Suzu)

**全名**：広瀬すず / Hirose Suzu

**中文常用称呼**：广濑铃，昵称"すず"、"小铃铛"

**代表作**：《海女》あまちゃん（2013，饰 青年天野夏）、电影《四月是你的谎言》四月は君の嘘（2016，饰 宫园薰）、电影《海街日记》海街diary（2015，饰 浅野铃）、电影《恋如雨止》恋は雨上がりのように（2018，饰 橘晶）

**特点**：令和时代最具代表性的新生代女演员之一，清纯灵动的"国民妹妹"形象，凭借《海女》崭露头角后全面进军电影界；姐姐广濑爱丽丝也是演员。辨识点是元气十足的笑容与清澈眼神。

**照片**：<img src="images/jp_06_hirose.jpg">

## 7. 绫濑遥 (綾瀬はるか / Ayase Haruka)

**全名**：綾瀬はるか / Ayase Haruka

**中文常用称呼**：绫濑遥，昵称"はるか"、"遥酱"

**代表作**：电视剧《在世界中心呼唤爱》世界の中心で、愛をさけぶ（2004，饰 广濑亚纪）、《白夜行》白夜行（2006，饰 西本雪穗）、电视剧《仁医》JIN-仁-（2009，一人分饰 橘恭／野风 两角）、《掟上今日子的备忘录》掟上今日子の備忘録（2015，饰 掟上今日子）

**特点**：实力与人气兼备的国民女演员，既能驾驭清纯初恋角色，也能演绎复杂暗黑人物，多次获得日剧学院赏主演女优奖。辨识点是温柔治愈的气质与自然细腻的哭戏。

**照片**：<img src="images/jp_07_ayase.jpg">

## 8. 长泽雅美 (長澤まさみ / Nagasawa Masami)

**全名**：長澤まさみ / Nagasawa Masami

**中文常用称呼**：长泽雅美，昵称"まさみ"、"麻酱"（中国粉丝爱称）

**代表作**：电影《在世界中心呼唤爱》世界の中心で、愛をさけぶ（2004，饰 广濑亚纪）、电影《泪光闪闪》涙そうそう（2006，饰 新垣加奈）、电影《海街日记》海街diary（2015，饰 佳乃）、电影《行骗天下JP》コンフィデンスマンJP（2018，饰 达科塔）

**特点**：从"东宝灰姑娘"选拔出道的国民级女演员，戏路宽广，从纯爱片到悬疑片均表现出色；凭借《泪光闪闪》等作品成为平成纯爱片代表面孔。辨识点是爽朗大气的笑容与亲和力。

**照片**：<img src="images/jp_08_nagasawa.jpg">

## 9. 役所广司 (役所広司 / Yakusho Koji)

**全名**：役所広司 / Yakusho Koji

**中文常用称呼**：役所广司，粉丝常称"役所叔"

**代表作**：《谈谈情跳跳舞》Shall we ダンス?（1996，饰 杉山正平）、《失乐园》失楽園（1997，与黑木瞳共演禁忌之恋）、电影《完美的日子》パーフェクト・デイズ（2023，饰 平山，获戛纳电影节最佳男演员奖）、电影《巴别塔》Babel（2006，与菊地凛子共演父女线）

**特点**：日本最具国际影响力的实力派男演员之一，凭借《完美的日子》获戛纳电影节最佳男演员奖；擅长演绎普通中年男性的隐忍与爆发。辨识点是沉稳厚重的气场与细腻内敛的表演。

**照片**：<img src="images/jp_09_yakusho.jpg">

## 10. 天海祐希 (天海祐希 / Amami Yuki)

**全名**：天海祐希 / Amami Yuki

**中文常用称呼**：天海祐希（也写作天海佑希），粉丝称"女王"

**代表作**：《女王的教室》女王の教室（2005，饰 阿久津真矢）、《顶级播音员》トップキャスター（2006，饰 桐岛春子）、《Around 40》Around40～注文の多いオンナたち～（2008，饰 绪方聪子）、《BOSS》BOSS（2009，饰 大泽绘里子）

**特点**：宝冢歌剧团男役出身的"大女主专业户"，以干练飒爽的职场女性形象深入人心，《女王的教室》成为一代人的"心理阴影"与经典；中年后转型成功堪称行业典范。辨识点是英气逼人的眼神与低沉有磁性的嗓音。

**照片**：<img src="images/jp_10_amami.jpg">

## 11. 渡边谦 (渡辺謙 / Watanabe Ken)

**全名**：渡辺謙 / Watanabe Ken

**中文常用称呼**：渡边谦（也写作渡边谦），好莱坞常称 Ken Watanabe

**代表作**：电影《最后的武士》ラスト・サムライ（2003，饰 胜元，获奥斯卡最佳男配角提名）、电影《艺伎回忆录》SAYURI（2005，饰 主席岩村）、电影《盗梦空间》Inception（2010，饰 斋藤）、电影《明日的记忆》明日の記憶（2006，主演阿尔茨海默病题材催泪佳作）

**特点**：成功进军好莱坞的日本演员代表，凭借《最后的武士》获奥斯卡及金球奖最佳男配角提名；以威严厚重的东方男性形象闻名世界影坛。辨识点是高大的身形与充满故事感的沧桑面容。

**照片**：<img src="images/jp_11_watanabe.jpg">

## 12. 小栗旬 (小栗旬 / Oguri Shun)

**全名**：小栗旬 / Oguri Shun

**中文常用称呼**：小栗旬，粉丝称"栗子"、" Oguri"

**代表作**：《花样男子》花より男子（2005，饰 花泽类）、《热血高校》クローズ（2007，饰 泷谷源治）、《鲁邦三世》ルパン三世（2014，饰 亚森·鲁邦）、电影《银魂》銀魂（2017，饰 坂田银时）

**特点**：从偶像剧美少年成长为全能型演员兼导演，戏路横跨青春、动作、悬疑各类题材；凭借《热血高校》在中国年轻观众中人气极高。辨识点是深邃立体的五官与亦正亦邪的气质。

## 13. 山田孝之 (山田孝之 / Yamada Takayuki)

**全名**：山田孝之 / Yamada Takayuki

**中文常用称呼**：山田孝之，粉丝称"熊猫"（其自嘲式昵称）

**代表作**：《在世界中心呼唤爱》世界の中心で、愛をさけぶ（2004，饰 松本朔太郎）、《热血高校》クローズ（2007，饰 芹泽多摩雄）、《勇者义彦与魔王之城》勇者ヨシヒコと魔王の城（2011，饰 义彦）、网剧《全裸导演》全裸監督（2018，饰 村西透）

**特点**：被誉为"变色龙演员"，可塑性极强，从纯爱片男主到搞笑剧废柴到黑帮恶徒均能完美驾驭；自编自导自演的"自我吐槽"式活动方式也极具话题性。辨识点是独特的丧萌气质与敬业的全情投入。

**照片**：<img src="images/jp_13_yamada.jpg">

## 14. 妻夫木聪 (妻夫木聡 / Tsumabuki Satoshi)

**全名**：妻夫木聡 / Tsumabuki Satoshi

**中文常用称呼**：妻夫木聪，粉丝称"妻夫木"、"小聪"

**代表作**：电影《五个扑水的少年》ウォーターボーイズ（2001，饰 铃木智）、电影《Jose与虎与鱼们》ジョゼと虎と魚たち（2003，饰 恒夫）、电影《恶人》悪人（2010，饰 清水佑一，获日本电影学院奖最佳男主角）、电影《如父如子》そして父になる（2013，饰 野野宫良多）

**特点**：阳光少年感与深度演技兼备的实力派，从青春片出道到凭《恶人》等作品确立影坛地位；在是枝裕和等名导作品中均有出色表现。辨识点是灿烂的笑容与亲和的邻家气质。

## 15. 苍井优 (蒼井優 / Aoi Yu)

**全名**：蒼井優 / Aoi Yu

**中文常用称呼**：苍井优，昵称"ゆう"、"优酱"

**代表作**：电影《关于莉莉周的一切》リリイ・シュシュのすべて（2001，饰 津田诗织）、电影《扶桑花女孩》フラガール（2006，饰 谷川富美，获日本电影学院奖最佳女主角）、电影《蜂蜜与四叶草》ハチミツとクローバー（2006，纯爱漫改代表作）、电影《蜂蜜与四叶草》ハチミツとクローバー（2006，饰 花本叶久美）

## 16. 吉永小百合 (吉永小百合 / Yoshinaga Sayuri)

**全名**：吉永小百合 / Yoshinaga Sayuri

**中文常用称呼**：吉永小百合，尊称"小百合女士"、"永远的女神"

**代表作**：电影《伊豆的舞女》伊豆の踊子（1963，饰 薰）、电影《爱与死》愛と死をみつめて（1963，饰 大岛道子）、电影《海峡》海峡（1982，与高仓健共演）、电影《母亲》母べえ（2008，饰 野上佳代）

**特点**：昭和时代至今活跃超过六十年的"国民女神"，多次获得日本电影学院奖等各大奖项最佳女主角；少女时代即是日活青春片顶流，年逾古稀仍是影坛常青树。辨识点是优雅端庄的和风气质与永恒的笑容。
